# Pokemon Text-Based Game

## Overview

A console-based Pokemon game developed in C++ that allows players to select a Pokemon and interact with game systems through a text-driven interface.

This project is being developed to practice Object-Oriented Programming (OOP) concepts and software design principles in C++.

## Features

* Pokemon selection system
* Different Pokemon types
* Player management
* Text-based gameplay
* Modular class structure

## Technologies Used

* C++
* Object-Oriented Programming
* Visual Studio

## Project Structure

* `Pokemon` - Core Pokemon class and functionality
* `Player` - Player-related logic
* `Utility` - Helper functions
* `PokemonType` - Pokemon type definitions
* `PokemonChoice` - Pokemon selection options

## Learning Objectives

* Classes and Objects
* Encapsulation
* Inheritance
* Polymorphism
* Enums and Structured Code Organization
